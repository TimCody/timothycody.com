Workpapers: from buggy MVP to enterprise product

I inherited a revenue-blocked, bug-ridden pre-sales MVP. The fix was a full re-architecture, an unpopular call at the time. I made the case, won a 40-engineer vote against competing proposals, and led the rebuild.

Senior Software Engineer · Intelligration / CWF Managers · 2015–2020

Vestly: a trading game with a million players

Vestly let anyone pick stocks with virtual money and win real cash prizes. It started as an MVP and grew to over a million users on iOS and Android, while the same data fed a hedge fund’s research.

  • Backend Node API serving the mobile apps, hosted serverlessly on AWS
  • A trading engine built to handle thinly traded penny stocks
  • Redis caching, scheduled ETL jobs and an admin portal
  • Worked with the data science team to turn data into signals the fund traded on
